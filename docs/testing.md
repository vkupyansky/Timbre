# Тестирование

Команды выполняются из корня проекта с Python 3.12 и `uv`. Зависимости устанавливаются по существующим lock-файлам.

## Автоматическая проверка

```sh
uv run --frozen python -m scripts.check
```

Команда проверяет форматирование, линтер, строгие типы, тесты с предупреждениями как ошибками, совместимость и известные уязвимости зависимостей, дистрибутивы, Compose и изолированный контейнер на отдельном порту. Она собирает образ, но не заменяет рабочий контейнер и не отправляет сообщения через Telegram.

Тесты не требуют рабочие credentials, записи, голоса и БД. Они проверяют права, границы данных, повторные события, отмену, доставку, миграции и восстановление. Успех изолированного контура не подтверждает внешнюю доставку и слуховое качество.

## Локальные модели

Для проверки цепочки нужны подготовленные модели, образец речи 15–20 секунд, входящее голосовое, собранный образ `shift:0.1.0` и свободный порт 8765:

```sh
uv run --frozen python -m scripts.accept_local \
  --reference /path/to/reference.wav \
  --source /path/to/speech.ogg
```

Используются временная служба и локальный транспорт вместо Telegram. Запускайте проверку последовательно и отдельно от рабочего сервиса; его порт занимать нельзя. Прохождение цепочки не заменяет прослушивание результата и проверку живой доставки.
