# Текущее состояние

## Реализовано

- Локальный синтез русской речи: Fish S2 Pro BF16 через MLX. Голосовые сообщения распознаются Whisper-small через MPS и проходят через тот же синтез.
- Закрытый доступ по `TELEGRAM_ADMIN_USER_IDS`, личные голоса, настройки и выбранный профиль у каждого разрешённого пользователя.
- Создание голоса через бот, автоматическая расшифровка образца, до трёх образцов одного человека, сравнение кандидата перед применением.
- Настройки подачи, скорости и параметров синтеза у голоса; пример с текущими настройками. Поддержан акустический контекст для шёпота.
- Единственная команда `/start`, кнопочная навигация в одной панели, отдельное обновляемое сообщение состояния каждого задания с отменой и повтором доставки.
- SQLite v9 с миграциями, восстановлением незавершённых файловых операций и постоянной историей текстов, расшифровок и снимков настроек.
- Docker Compose для приложения и отдельная пользовательская служба macOS для моделей. Зависимости и модели закреплены lock-файлами и контрольными суммами.

## Проверки

Документированная полная проверка: `uv run --frozen python -m scripts.check`. Она выполняет линтер, форматирование, строгие типы, тесты с warnings as errors, проверки зависимостей, сборку и изолированный контейнерный сценарий. Тесты охватывают изоляцию пользователей, приватный доступ, поддельные и устаревшие кнопки, повторные события, отмену, доставку, миграции и восстановление.

9 ноября 2026 года проверен чистый экспорт исходников без конфигурации, базы и голосов: 459 тестов приложения и 202 ML-теста прошли. Форматирование, линтер, строгие типы, совместимость и аудит зависимостей, сборка дистрибутивов с проверкой состава, Docker Compose и изолированный запуск контейнера прошли. В проверяемых Python-зависимостях известных уязвимостей не обнаружено. Основные ML-пакеты и ревизии моделей сохранены; исправлены уязвимые вспомогательные зависимости.

Этот прогон не запускал реальные модели и не отправлял сообщения через Telegram. Слуховая оценка и доставка в реальный чат проверяются отдельно.

Реальный сценарий локальных моделей: `scripts.accept_local` с явно переданными записями. Для него нужен свободный порт 8765. Telegram заменяется локальным транспортом; успешное прохождение не означает проверки внешней доставки или слухового качества.

Приватные отчёты, аудио, база, ключи и установленное окружение не включены в репозиторий. Они не нужны для обычных изолированных тестов. Наличие исходников не означает, что модели и пользовательская служба уже подготовлены на новом компьютере.

## Ограничения

- Целевая платформа обработчика: Apple Silicon с Metal/MPS. Чистая установка требует однократной подготовки службы и моделей; Compose самостоятельно её не выполняет.
- Установленный сервис может размещаться отдельно от исходников и запускать приложение из готового Docker-образа. Служебный каталог с нативным обработчиком, моделями, ключами и данными должен оставаться на Mac. Порядок размещения и переноса описан в [архитектуре](ARCHITECTURE.md#исходники-и-установленный-сервис).
- Паузы, темп и эмоции входящего голосового не переносятся. Подача задаётся в профиле.
- Эмоциональные подсказки, произношение и сходство с образцом требуют прослушивания. Смена эмоций внутри длинного сообщения не гарантируется.
- Модель не удерживается постоянно в памяти между всеми заданиями. Обработка последовательная, её длительность зависит от длины текста и аппаратуры.
- Таймаут Telegram может означать уже выполненную отправку. Неоднозначная доставка требует решения пользователя; точное отсутствие дублей в этом случае не гарантируется API.
- Голоса и записи не поставляются с исходниками. В чистом экземпляре первый профиль добавляется через бот.
- Оплата и публичная регистрация не включены. Лицензия весов Fish требует отдельного разрешения для коммерческого применения.
