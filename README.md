# Timbre

Telegram-бот с локальными моделями для русской речи. Текст превращается в голосовое выбранным голосом. Входящее голосовое сначала распознаётся, затем озвучивается тем же голосом и с его настройками. Паузы и эмоции исходной записи не копируются.

## Запуск

Целевая платформа: macOS на Apple Silicon с Metal/MPS и Docker Desktop. Нативный обработчик моделей должен быть подготовлен один раз по [инструкции сопровождения](docs/ARCHITECTURE.md#первичная-установка).

При первой установке создайте `.env` по образцу [.env.example](.env.example). В нём нужны только два параметра:

| Параметр | Назначение |
| --- | --- |
| `TELEGRAM_BOT_TOKEN` | Токен бота от BotFather |
| `TELEGRAM_ADMIN_USER_IDS` | Положительные числовые Telegram ID через запятую |

Файл `.env` должен принадлежать пользователю, запускающему сервис, и иметь права `0600`. Без корректных значений приложение не запускается. Внутренний ключ создаётся автоматически один раз.

```sh
docker compose up -d --build
```

Compose запускает приложение и SQLite. Модели работают в отдельной пользовательской службе macOS: Linux-контейнер не получает доступ к Apple GPU. Служба запускается при входе пользователя и ждёт приложение. Mac должен быть включён, пользователь должен оставаться в системе, Docker Desktop должен работать.

После изменения `.env` пересоздайте контейнер:

```sh
docker compose up -d --force-recreate
```

Установленный сервис можно разместить отдельно от исходников. В такой установке приложение запускается из готового образа через Docker Desktop или Compose без `--build`; модели и закрытые данные остаются в служебном каталоге на Mac. Удалять этот каталог нельзя. [Размещение и запуск установленного сервиса](docs/ARCHITECTURE.md#исходники-и-установленный-сервис).

## Использование

1. Откройте личный чат с ботом и нажмите `/start`.
2. В разделе "Мои голоса" нажмите "Добавить голос". Отправьте 15–20 секунд чистой русской речи одного человека и задайте название.
3. Дождитесь подготовки профиля и прослушайте новый пример. Готовый голос можно выбрать и настроить в его карточке.
4. Отправьте текст или голосовое. Бот пришлёт результат обычным голосовым сообщением.

Только `/start` является командой. Остальное управление работает через кнопки в одной панели. `/start` переносит главную вниз чата. У каждого запроса отдельное короткое сообщение со статусом, отменой и при необходимости повтором отправки.

Голоса, выбранный профиль и настройки разделены по пользователям. Доступ к боту имеют только ID из `.env`. Посторонним бот не отвечает и не скачивает их файлы. Даже администратор не получает доступ к чужим голосам через интерфейс.

У каждого голоса сохраняются подача, скорость, инструкция и параметры синтеза. Их не нужно выбирать перед каждым сообщением. Можно добавить до трёх образцов одного человека, сравнить новый пример с прежним и применить изменения. До подтверждения используется прежний набор. Дополнительные образцы служат контекстом модели, обучение весов не выполняется.

Частные голоса и записи в репозиторий не входят. В чистой установке сначала добавьте свой голос через бот. Локально настроенный стартовый профиль может копироваться в независимые личные профили; его удаление пользователем не создаёт копию заново.

Для ударения можно выделить гласную: `замОк`, `зАмок`. Букву `ё` лучше писать явно. Это подсказка модели, результат нужно проверять прослушиванием. Управление эмоциями и сходство с образцом также не гарантируются одними настройками.

## Ограничения и данные

Текст и расшифровка ограничены 2000 символами, входящее голосовое: 120 секундами и 10 МиБ, результат: 180 секундами и 20 МиБ. Обработка одного задания ограничена 15 минутами. Задания моделей выполняются последовательно.

Модели работают локально; сообщения и аудио передаются через Telegram. Настройки, профили и SQLite сохраняются в `.shift/` между перезапусками. История текстов и настроек в БД хранится постоянно; временные записи, результаты и черновики очищаются в течение 24 часов. Подробности: [данные и отчёты](docs/DATA.md).

Оплата не подключена. Разрешённые администраторы пользуются ботом без списания времени. Учёт прежних аккаунтов сохраняется при обновлениях.

## Разработка

Python 3.12, `uv`. Зависимости закреплены в `uv.lock` и `ml/uv.lock`; ревизии и SHA-256 моделей: `models/tts.lock.json` и `models/asr.lock.json`. Текущий стек: Fish S2 Pro BF16 через MLX и Whisper-small через MPS.

```sh
uv run --frozen python -m scripts.check
```

Проверка включает форматирование, линтер, строгие типы, тесты с warnings as errors, зависимости, сборку и изолированный запуск контейнера. Она не отправляет сообщения в рабочий бот.
